Partner Install Snippet

Partners copy this one line into their website:

<script src="https://saverwell.com/widget/v1/embed.js" data-partner="YOUR-NAME" data-zip="YOUR-ZIP"></script>

Verification Checklist

  • Widget renders in a Shadow DOM (inspect element to confirm)
  • All outbound links contain utm_source=partner&utm_campaign=...
  • Email signup POSTs to /widget/v1/api/subscribe
  • Success/error states display correctly after signup
  • Dark theme renders with dark background and light text
  • Widget is responsive in narrow containers
  • Logo fallback shows first letter when image fails to load
  • "Powered by Saverwell" footer links to saverwell.com with UTM params
