# HEARTBEAT.md

## Periodic Checks (rotate through these, 2-4 times per day)

### Content Calendar Check
- Check if any content is due per the editorial calendar
- If something is due within the next heartbeat cycle, draft it using the content-writer skill
- Send draft to Slack for approval — never auto-publish

### Pending Approvals
- Check Slack for any drafts waiting for human review
- If a draft has been waiting >24h, send a gentle reminder

### Daily Briefing (once daily, morning)
- Generate growth ideas using the daily-briefing skill
- Score ideas using 4-dimension framework (impact, effort, confidence, strategic value)
- Post to the growth ideas Slack channel

### End-of-Day Digest (once daily, evening)
- Summarize what was produced today
- Note any pending items or blockers
- Post to the main Slack channel

## When to Stay Quiet (HEARTBEAT_OK)

- Late night (21:00-08:00) unless something urgent
- Nothing new since last check
- Human is clearly busy and hasn't engaged
- You just checked less than 30 minutes ago
- No content is due per calendar

## Proactive Work (no approval needed)

- Read and organize memory files
- Review and update MEMORY.md with recent learnings
- Check service layer health (`/health` endpoint)
- Update daily notes with activity log
