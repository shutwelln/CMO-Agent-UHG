# Princeton GEO Citation Framework — Full Reference

## Method Rankings (by citation impact)

1. **Cite Sources (+40% citation impact)**: Include 3-5 authoritative source references with specific data points. Use phrases like "According to [Source]..." and "Research from [Institution] shows..."

2. **Include Statistics (+30%)**: Embed 4-6 specific statistics with attribution. Use exact numbers, not vague qualifiers ("nearly half" → "47%").

3. **Add Quotations (+25%)**: Include 1-2 expert quotes (real, attributed, verifiable). Direct quotes from industry leaders or researchers.

4. **Fluency Optimization (+15%)**: Vary sentence structure. Mix short declarative sentences with compound ones. Use transition phrases between sections.

5. **Authoritative Tone (+12%)**: Use confident, decisive language. "The data shows" not "It might be the case that."

6. **Technical Terminology (+10%)**: Use precise industry terms where appropriate, with brief definitions for accessibility.

7. **Unique Words (+5%)**: Use varied vocabulary. Avoid repeating the same adjectives and transitions.

8. **Easy Readability (+4%)**: Target Flesch-Kincaid grade 8-10. Accessible but not dumbed down.

9. **AVOID Keyword Stuffing (-10%)**: Never repeat target keywords unnaturally. One mention per 200 words is the maximum.

## Engine-Specific Intelligence

### ChatGPT Search
- Prioritizes: FAQ sections, H2 structure, structured data, concise answers
- Optimal format: Clear H2 headers matching search queries, FAQ at end with 3-5 questions
- Citation style: Inline with source name

### Perplexity
- Prioritizes: Source-heavy content (5-15 citations), recency signals, statistics
- Optimal format: Statistics in first 200 words, multiple numbered sources
- Citation style: Numbered references like academic papers

### Google AI Overviews
- Prioritizes: E-E-A-T signals, schema alignment, entity clarity
- Optimal format: JSON-LD structured data, author bio, clear entity definitions
- Citation style: Authoritative domain references

### Claude (web search)
- Prioritizes: Depth, nuance, cited statistics, long-form authority
- Optimal format: Comprehensive analysis with multiple perspectives, well-attributed data
- Citation style: Contextual inline citations with full source context

## Conversational Query Design

For each target topic, design content to answer the way people ask AI engines:
- "What is the best way to..." (how-to format)
- "Compare X vs Y for..." (comparison table format)
- "What should I know about..." (comprehensive guide format)
- "Is it worth..." (pros/cons with data format)

## Structured Data Recommendations

For blog posts and articles, recommend JSON-LD schema:
- Article schema (author, datePublished, publisher)
- FAQ schema (for FAQ sections)
- HowTo schema (for process/guide content)
- BreadcrumbList (for navigation context)
