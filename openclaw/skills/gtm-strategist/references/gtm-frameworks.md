# GTM Frameworks — Complete Reference

## Phase 1: VALIDATION (2-4 weeks)

**Goal:** Prove message-market fit with tight beachhead

**Actions:**
- Define ICP with beachhead segment
- Build minimal landing page with conversion tracking
- Run 2-3 channel experiments (small budget)
- Conduct 10-20 customer conversations
- Test core value prop messaging

**Exit Criteria:**
- [ ] ICP validated with real conversations/signals
- [ ] Landing page live with conversion tracking
- [ ] First 50-100 signups or waitlist entries
- [ ] Core value prop tested in 2-3 channel experiments

## Phase 2: CONTROLLED LAUNCH (4-8 weeks)

**Goal:** Scale initial traction with repeatable loops

**Actions:**
- Scale winning channels from Phase 1
- Launch lifecycle email/SMS flows
- Implement full analytics and attribution
- Begin content marketing engine
- Track unit economics weekly

**Exit Criteria:**
- [ ] CAC within 2x target
- [ ] Activation rate above minimum threshold
- [ ] At least 1 channel producing consistent volume
- [ ] Retention signals validated (D7/D30 cohorts)

## Phase 3: SCALED EXPANSION (8-16 weeks)

**Goal:** Expand to adjacent segments, optimize unit economics

**Actions:**
- Expand to second beachhead segment
- Launch paid acquisition at scale
- Implement referral/viral loops
- Optimize CAC through channel mix modeling
- Build partnership/affiliate channel

**Exit Criteria:**
- [ ] CAC at or below target across 2+ channels
- [ ] LTV:CAC ratio > 3:1
- [ ] Second segment validated
- [ ] Revenue/monetization tracking to plan

- Funnel role (awareness/consideration/conversion/retention)
- Estimated CAC range
- Success metric
- Priority (1-5)
- Rationale for priority ranking

## Risk Assessment Categories

1. **Execution Risk** — Team capacity, technical complexity, timeline
2. **Channel Risk** — Platform dependency, algorithm changes, cost volatility
3. **Regulatory Risk** — Compliance requirements, industry-specific rules
4. **Operational Risk** — Scaling bottlenecks, support capacity, infrastructure
5. **Market Risk** — Competition, timing, demand uncertainty
